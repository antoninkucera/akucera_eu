## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Content & Publishing

- Standalone long-form articles in `docs/` are prepared for publication on Substack (English).
- Substack editor does not support vector SVG uploads directly; always export/provide diagrams as high-resolution raster images (PNG/JPG) in `docs/images/`.

### Writing Guardrails (Antonin's Voice)

- **No AI slop or dramatic buzzwords:** Avoid filler verbs and dramatic phrases ("delve", "tapestry", "revolutionize", "beacon", "game-changer", "testament", "hit the nail on the head", "peel back the layers", "tectonic shift").
- **No long dashes:** Absolutely NO em-dashes (`—`) or en-dashes (`–`). Use standard hyphens (`-`), commas, parentheses, or restructure the sentence into clean punctuation.
- **Tone:** Grounded, direct, pragmatic practitioner perspective. Written in first person ("I", "we"), drawing on real-world engineering and data leadership experience (budgets, tech debt, team friction, messy data reality). Matter-of-fact, candid, zero marketing fluff.
